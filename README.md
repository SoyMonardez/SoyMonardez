# Hola, soy Alejo Monárdez

### Desarrollador de software enfocado en backend, SaaS e inteligencia artificial aplicada

Construyo sistemas SaaS, APIs y automatizaciones orientadas a resolver necesidades reales. Trabajo principalmente con Python, FastAPI, PostgreSQL, React y Docker.

Integro inteligencia artificial en funciones como asistentes conversacionales, procesamiento de voz y contenido, extracción de información y automatización de procesos.

Estudio la Licenciatura en Ciencia de Datos en la Universidad Siglo 21.

## Proyectos destacados

### [MiTurno](https://github.com/SoyMonardez/MiTurno)

SaaS multi-tenant para negocios de servicios. Centraliza reservas, disponibilidad, profesionales y gestión operativa, con una experiencia pública para clientes y herramientas administrativas para cada negocio.

**Stack:** Python, FastAPI, PostgreSQL, React, Redis, Celery y Docker.

### [FinBot WhatsApp](https://github.com/SoyMonardez/bot_whatsapp)

Bot para registrar y consultar movimientos financieros familiares desde WhatsApp mediante texto o audio. Utiliza modelos de voz y lenguaje para interpretar movimientos y responder consultas sobre los registros.

**Stack:** Python, FastAPI, PostgreSQL, SQLAlchemy, Groq, Whisper, Evolution API y Docker.

### [Sistema de Presupuestos](https://github.com/SoyMonardez/sistema-presupuestos)

Aplicación para crear presupuestos por ítems, calcular totales, exportar documentos en PDF e interpretar descripciones libres mediante Groq.

**Stack:** Node.js, Express, SQLite, JavaScript y Docker.

### [Etán Construcciones](https://github.com/SoyMonardez/Et-n_portafolio_empresa)

Sitio institucional y sistema de gestión de contenidos para una constructora. Incluye catálogo de servicios, obras, maquinaria, formularios y panel administrativo.

**Stack:** React, Node.js, Express, PostgreSQL, Vite y Docker.

### [Armario digital](https://github.com/SoyMonardez/armario-digital)

Prototipo mobile-first para organizar prendas, componer outfits y explorar una experiencia de asesoría de estilo.

**Stack:** React, TypeScript, Vinext, Vite y Cloudflare Workers.

### [Portfolio personal](https://github.com/SoyMonardez/portafolio_AlejoMonardez)

Aplicación para presentar y administrar proyectos, con contenido bilingüe, panel de gestión y formulario de contacto.

**Stack:** React, Node.js, Express y MySQL.
